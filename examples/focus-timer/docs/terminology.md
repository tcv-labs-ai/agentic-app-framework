# Terminology

## Product Terms

- `work session`: a focused period of work activity
- `break session`: a recovery period that follows a work session
- `phase`: the current session type, either work or break
- `remaining time`: the amount of time left in the current phase
- `configured duration`: the user-selected duration for work or break

## UX Terms

- `start`: begin a timer that has not started yet
- `pause`: freeze the active timer without losing elapsed progress
- `resume`: continue a paused timer from its current remaining time
- `reset`: return the timer to the beginning of the current phase
