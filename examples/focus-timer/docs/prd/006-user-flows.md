# PRD 006: User Flows

## First-Time User Flow

1. open the app
2. review the default durations
3. optionally adjust work and break minutes
4. start the timer

## Returning User Flow

1. open the app
2. see the most recently saved durations
3. start or adjust the next session

## Pause and Reset Flow

1. start a phase
2. pause it
3. resume or reset it
