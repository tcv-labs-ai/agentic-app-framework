# PRD 004: Platform and Accessibility

## Must

- support modern desktop browsers
- remain usable on narrower screens
- provide clear labels for controls
- maintain readable timer hierarchy and sufficient contrast

## Should

- support keyboard operation for core controls
- remain stable at larger text sizes where practical

## Won't

- implement platform-specific native desktop behavior in MVP

## Acceptance Criteria

- the app works in a browser without a build step
