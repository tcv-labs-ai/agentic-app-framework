# PRD 001: Product Foundation

## Audience

- people who want a lightweight focus timer without a full productivity suite

## Problem Statement

Users often want a simple way to structure focused work and breaks without opening a heavy task manager or distraction-heavy timer app.

## Product Promise

Focus Timer provides a calm, browser-first timer that helps users maintain a simple work and break rhythm.

## Must

- support configurable work and break durations
- clearly show the current phase and remaining time
- support start, pause, resume, and reset

## Should

- remember the configured durations locally in the browser
- feel deliberate on desktop browser widths

## Won't

- include task management
- include authentication or cloud sync
- include analytics or reporting in MVP

## Acceptance Criteria

- a user can configure durations and run a full work/break cycle in the browser
