# Design System

## Strategy

The example uses a small custom design layer on top of plain web technologies.

## Visual Rules

- one centered panel
- large timer display
- compact controls
- work and break phases differentiated by surface accents rather than heavy theming

## Token Categories

- color roles
- spacing scale
- radius scale
- type scale

## Formatting Rules

- timer values display as `MM:SS`
- durations in settings display as whole minutes
