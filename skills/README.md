# Skills

This directory is the version-controlled source for the reusable Codex skills in this repository.

| Skill | Purpose |
| --- | --- |
| `agentic-app-framework` | Bootstrap and maintain PRD, TDD, ADR, and project-state documentation in software repositories. |
| `session-continuity` | Preserve durable context, agent or human handoffs, and ready next-session prompts. |
| `tcv-labs-governance-skill` | Apply TCV Labs repository boundaries, security safeguards, and drift control. |
| `tcv-labs-ops-record` | Write non-secret TCV Labs records in the control-plane repository. |

The source here is canonical. Local installations under `~/.codex/skills/` are derived runtime copies and must be refreshed through the repository scripts.
