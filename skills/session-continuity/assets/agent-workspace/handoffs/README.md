# Session Handoffs

Create a handoff when a meaningful session leaves context that a future agent or maintainer would otherwise need to rediscover.

Use `YYYY-MM-DD-short-title.md`.

```md
# Session Handoff: YYYY-MM-DD Short Title

## Closeout

- Closed At: YYYY-MM-DD h:mm AM/PM [TIMEZONE]
- Closed By: [USER_OR_OPERATOR]

## Summary

- [What changed or was learned.]

## Files and Sources

- `[PATH_OR_URL]`: [Why it matters.]

## Decisions and Constraints

- [Decision, constraint, or `None`.]

## Validation

- [Check actually run, result, or `Not run`.]

## Open Questions

- [Question or `None`.]

## Next Suggested Step

- [Smallest safe continuation.]
```
